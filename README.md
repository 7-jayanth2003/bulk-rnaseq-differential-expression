# Bulk RNA-seq Differential Expression Analysis

## Project Overview

This project aims to analyse bulk RNA sequencing (RNA-seq) data to identify genes whose expression differs between two biological conditions.

The analysis will begin with gene-level count data and use DESeq2 in R for differential expression analysis. The project will then develop into a reproducible workflow with quality control, documented software environments, automated execution, and a final report.

## Objectives

- Understand the biological question and the sample metadata.
- Perform exploratory analysis of gene expression counts.
- Identify differentially expressed genes using DESeq2.
- Interpret results using statistical evidence and biological context.
- Develop a reproducible workflow with clear documentation.
- Publish the analysis and code on GitHub.

## Planned Workflow

1. Select and document a suitable public RNA-seq dataset.
2. Inspect sample metadata and gene-level counts.
3. Perform quality checks and exploratory analysis.
4. Conduct differential expression analysis with DESeq2.
5. Visualise and interpret the results.
6. Automate the analysis workflow.
7. Document the methods, software versions, and findings.

## Project Status

**Status:** Initial setup.

The dataset has not yet been selected, and the analysis has not yet been performed. Results and conclusions will be added after the analysis is completed and validated.
